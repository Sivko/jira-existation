# Политика конфиденциальности — Jira: боковая панель (Existation Jira)

Последнее обновление: 12 июля 2026 г.

## Какие данные обрабатывает расширение

- Настройки подключения к Jira: URL сервера, логин/email, API-токен, JQL-запрос.
- Данные задач Jira: ключ, название, статус, тип, приоритет, ссылки.
- Лента активности: комментарии и события назначения по вашим задачам.
- Недавние и избранные задачи, время последнего открытия.

## Где хранятся данные

Все данные хранятся локально в браузере пользователя (chrome.storage.local).
Разработчик не получает, не продаёт и не передаёт эти данные третьим лицам.

## Куда передаются данные

Расширение отправляет запросы только на Jira-сервер, URL которого вы указали,
для авторизации и работы с Jira REST API (просмотр задач, активности, worklog).

## Разрешения Chrome

- storage — локальное хранение настроек и кэша.
- sidePanel — интерфейс в боковой панели.
- tabs — открытие задач и учёт недавно просмотренных страниц Jira.
- alarms — фоновое обновление активности.
- host permissions — доступ к вашему Jira-серверу (адрес задаётся вами).

## Удалённый код

Расширение не загружает и не выполняет удалённый JavaScript.
